## Spec errors found
- race.md race_logic kind 4: bracket delay is **7** ticks per tenth (`d*7`), not 13.
- race.md crash_show: picture B (0x812) is a plain blit (A0AE), not masked.
- race.md clock_draw: side length is q(q(3·L,2)·3,2) (9/16 of the table length) for both hands; hour tip q(3L,2),
  minute tip L.
- race.md tires_replace takes list[1] (second spare set; stack garbage with one set) and passes wear = NULL
  (writes DS:0000+n); port uses nodes[0] when only one set.
- race.md/race_render address of the Aqueduct flags read by player_advance: AQ[seg+2] (DS 4E66), noted.
- race_render 8674 poly_bottom_hit_bits: `any` is set by every point on row 0x65 (not only the counted ones), so a
  bottom edge wholly inside x 0x50..0x13F gives 0x60 (the obstacle under the car).
- race_render 9f08: the trough test reads byte [96F6-1Ch] = C[seg] (row k = 14), the spec's "F(0)" label is misleading.
- race_render bb22: the DS:80A0 scratch is the picture DS:AB24 (start_pic2, the starter slide picture): its header is
  re-initialised in place and its data buffer reused (overflows into the next arena-2 data if the rotation is larger).
